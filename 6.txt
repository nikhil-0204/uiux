
import numpy as np

# 1. Tic-Tac-Toe Environment
class TicTacToe:
    def __init__(self):
        self.reset()

    def reset(self):
        self.state = [0] * 9
        self.is_terminal = False

    def get_available_moves(self):
        return [i for i in range(9) if self.state[i] == 0]

    def make_move(self, move, player):
        self.state[move] = player

    def check_win(self, player):
        wins = [
            [0,1,2], [3,4,5], [6,7,8],
            [0,3,6], [1,4,7], [2,5,8],
            [0,4,8], [2,4,6]
        ]

        for p in wins:
            if all(self.state[i] == player for i in p):
                self.is_terminal = True
                return True
        return False

    def is_draw(self):
        return 0 not in self.state


# 2. Q-Learning Agent
class QLearningAgent:
    def __init__(self):
        self.lr = 0.9
        self.gamma = 0.9
        self.epsilon = 0.3
        self.q_table = np.zeros((3**9, 9))

    def get_state_index(self, state):
        return sum((3**i) * (mark + 1)
                   for i, mark in enumerate(state))

    def choose_action(self, state, moves):
        s = self.get_state_index(state)

        if np.random.random() < self.epsilon:
            return np.random.choice(moves)

        return moves[np.argmax(self.q_table[s, moves])]

    def update_q_table(self, state, action, next_state, reward):
        s = self.get_state_index(state)
        future = 0

        if next_state is not None:
            ns = self.get_state_index(next_state)
            moves = [i for i in range(9) if next_state[i] == 0]
            if moves:
                future = np.max(self.q_table[ns, moves])

        self.q_table[s, action] += self.lr * (
            reward + self.gamma * future - self.q_table[s, action]
        )


# 3. Training and Evaluation
def evaluate_agents(agent1, agent2, episodes=1000):
    game = TicTacToe()
    wins = [0, 0]
    draws = 0

    for _ in range(episodes):
        game.reset()
        agents = [agent1, agent2]
        marks = [1, -1]
        turn = 0

        while not game.is_terminal:
            state = game.state.copy()
            moves = game.get_available_moves()
            action = agents[turn].choose_action(state, moves)

            game.make_move(action, marks[turn])

            if game.check_win(marks[turn]):
                agents[turn].update_q_table(state, action, None, 10)
                wins[turn] += 1
                break

            if game.is_draw():
                agents[turn].update_q_table(state, action, None, 0)
                draws += 1
                break

            next_state = game.state.copy()
            agents[turn].update_q_table(state, action, next_state, -10)
            turn = 1 - turn

    return wins[0], wins[1], draws


# 4. Create Agents
agent1 = QLearningAgent()
agent2 = QLearningAgent()

# 5. Run and Display Results
agent1_wins, agent2_wins, draws = evaluate_agents(agent1, agent2)

print("Agent 1 wins:", agent1_wins)
print("Agent 2 wins:", agent2_wins)
print("Draws:", draws)

## **3. Building the Reinforcement Learning Model**

### **Step 7: Create Q-Learning Agent**

```
class QLearningAgent:    def __init__(self):        self.lr = 0.9        self.gamma = 0.9        self.epsilon = 0.3        self.q_table = np.zeros((3**9, 9))
```

This class creates an AI agent that learns which moves are better using Q-Learning.

**Important parameters:**

| Parameter       | Meaning                 |
| --------------- | ----------------------- |
| `lr = 0.9`      | Learning rate           |
| `gamma = 0.9`   | Discount factor         |
| `epsilon = 0.3` | Exploration probability |
| `q_table`       | Stores the Q-values     |

**1. Learning Rate (lr)**

- Controls how much new information affects the existing Q-value.
- Higher learning rate means faster updates.

**2. Discount Factor (gamma)**

- Determines the importance of future rewards.
- Higher gamma gives more importance to future rewards.

**3. Epsilon**

- Controls exploration.
- `epsilon = 0.3` means the agent chooses a random move with 30% probability.
- Otherwise, it chooses the move with the highest Q-value.

**4. Q-Table**

```
self.q_table = np.zeros((3**9, 9))
```

- Stores the value of taking each action in a particular game state.
- `3**9` represents the total number of possible board encodings.
- `9` represents the nine possible board positions.
- Initially, all Q-values are zero.

### **Step 8: Convert Game State into an Index**

```
def get_state_index(self, state):    return sum((3**i) * (mark + 1)               for i, mark in enumerate(state))
```

This function converts the game board into a single numerical index.

Explanation:

- `enumerate(state)`: Gets the position and value of each board cell.
- `mark + 1`: Converts board values from `-1, 0, 1` into `0, 1, 2`.
- `3**i`: Uses powers of 3 to create a unique encoding for each board arrangement.
- `sum()`: Adds the calculated values.

This index is used to access the corresponding row in the Q-table.

### **Step 9: Choose an Action**

```
def choose_action(self, state, moves):    s = self.get_state_index(state)    if np.random.random() < self.epsilon:        return np.random.choice(moves)    return moves[np.argmax(self.q_table[s, moves])]
```

This function decides which position the AI should select.

Explanation:

1. Converts the current board into a Q-table index.
2. Generates a random number.
3. If the number is less than epsilon, selects a random available move.
4. Otherwise, selects the available move with the highest Q-value.

This method is called the **Epsilon-Greedy Strategy**.

It balances two activities:

- Exploration: Trying new moves.
- Exploitation: Choosing the best-known move.

### **Step 10: Update the Q-Table**

```
def update_q_table(self, state, action, next_state, reward):    s = self.get_state_index(state)    future = 0
```

- Converts the current state into an index.
- Initializes the future reward value to zero.

```
if next_state is not None:    ns = self.get_state_index(next_state)    moves = [i for i in range(9) if next_state[i] == 0]    if moves:        future = np.max(self.q_table[ns, moves])
```

- Checks whether a next state exists.
- Converts the next state into an index.
- Finds the available moves in the next state.
- Selects the maximum Q-value among available moves.

```
self.q_table[s, action] += self.lr * (    reward + self.gamma * future - self.q_table[s, action])
```

This is the main Q-Learning update formula.

\\[ Q(s,a) \leftarrow Q(s,a)+ \alpha[r+\gamma\max Q(s',a')-Q(s,a)] \\]

Where:

- \\(Q(s,a)\\): Current Q-value.
- \\(\alpha\\): Learning rate.
- \\(r\\): Reward received.
- \\(\gamma\\): Discount factor.
- \\(s'\\): Next state.
- \\(a'\\): Next action.

The agent updates its knowledge based on the reward and future expected reward.
