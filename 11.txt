**Problem Statement:** Analyzing Air Quality Index (AQI) Trends in a City.

**Objective:** To analyze air pollution data and visualize AQI trends, pollutant levels, AQI distribution, and relationships between pollutants and AQI using Matplotlib.

Your code covers all the major tasks in the practical. Let's understand it step by step in simple language.

## **1. Import libraries**

```
import pandas as pdimport matplotlib.pyplot as plt
```

- `pandas`: Used to load and analyze the dataset.
- `matplotlib.pyplot`: Used to create graphs and visualizations.

## **2. Load dataset**

```
df = pd.read_csv("city_day.csv")
```

Loads the air quality dataset into a DataFrame.

```
print(df.head())
```

Displays the first five records.

```
print(df.shape)

```
print(df.columns.tolist())

```

```

## **3. Date conversion**

```
df["Date"] = pd.to_datetime(    df["Date"],    format="%Y-%m-%d")
```

Converts the Date column into Pandas datetime format.

- `pd.to_datetime()`: Converts text into date format.
- `%Y`: Year.
- `%m`: Month.
- `%d`: Day.

Date conversion is important for creating time-based graphs.

## **4. Summary statistics**

```
print(df.describe())
```

Displays statistical information about numerical columns.

It includes:

- `count`: Number of available values.
- `mean`: Average value.
- `std`: Standard deviation.
- `min`: Minimum value.
- `25%`: First quartile.
- `50%`: Median.
- `75%`: Third quartile.
- `max`: Maximum value.

## **5. AQI trend over time – Line plot**

```
plt.figure(figsize=(10, 5))plt.plot(    df["Date"],    df["AQI"],    marker="o")plt.title("AQI Trend Over Time")plt.xlabel("Date")plt.ylabel("AQI")plt.xticks(rotation=45)plt.grid(True)plt.tight_layout()plt.show()
```

This graph shows how the Air Quality Index changes over time.

Explanation:

- `plt.figure()`: Creates a new figure.
- `figsize=(10,5)`: Sets the graph size.
- `plt.plot()`: Creates a line graph.
- `marker="o"`: Displays circular markers on data points.
- `plt.title()`: Adds a graph title.
- `plt.xlabel()`: Adds the X-axis label.
- `plt.ylabel()`: Adds the Y-axis label.
- `plt.xticks(rotation=45)`: Rotates date labels by 45 degrees.
- `plt.grid(True)`: Displays grid lines.
- `plt.tight_layout()`: Adjusts spacing.
- `plt.show()`: Displays the graph.

**Purpose:** To identify whether air quality is improving or becoming worse over time.

## **6. Pollutant levels over time – Line plot**

```
plt.figure(figsize=(10, 5))plt.plot(df["Date"], df["PM2.5"], label="PM2.5")plt.plot(df["Date"], df["PM10"], label="PM10")plt.plot(df["Date"], df["CO"], label="CO")plt.title("Pollutant Levels Over Time")plt.xlabel("Date")plt.ylabel("Pollutant Level")plt.legend()plt.xticks(rotation=45)plt.grid(True)plt.tight_layout()plt.show()
```

This graph displays the changes in different pollutant levels over time.

- `PM2.5`: Fine particulate matter with a diameter of 2.5 micrometres or less.
- `PM10`: Particulate matter with a diameter of 10 micrometres or less.
- `CO`: Carbon monoxide.

Important functions:

- `plt.plot()`: Creates line graphs.
- `label`: Assigns names to each line.
- `plt.legend()`: Displays the names of the lines.

**Purpose:** To compare the pollution levels of PM2.5, PM10, and CO over time.

## **7. AQI comparison by date – Bar plot**

## **8. AQI distribution – Box plot**

```
plt.figure(figsize=(7, 5))plt.boxplot(df["AQI"].dropna())plt.title("AQI Distribution")plt.ylabel("AQI")plt.show()
```

This graph shows the distribution of AQI values.

- `plt.boxplot()`: Creates a box plot.
- `dropna()`: Removes missing AQI values before plotting.
- `plt.title()`: Adds the graph title.

A box plot displays:

- Minimum value (excluding outliers).
- First quartile (Q1).
- Median (Q2).
- Third quartile (Q3).
- Maximum value (excluding outliers).
- Outliers as individual points.

**Purpose:** To understand the spread of AQI values and identify unusually high or low values.
