
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
import seaborn as sns

# 1. Load Dataset
data = pd.read_csv(r"C:\Users\Asus\Downloads\CMPL\Iris.csv")

# 2. Select Features
X = data.drop(['Id', 'Species'], axis=1)

# 3. Elbow Method
wcss = []

for k in range(1, 11):
    model = KMeans(n_clusters=k, random_state=42, n_init=10)
    model.fit(X)
    wcss.append(model.inertia_)

# 4. Plot Elbow Graph
plt.plot(range(1, 11), wcss, marker='o')
plt.xlabel("Number of Clusters (K)")
plt.ylabel("WCSS")
plt.title("Elbow Method")
plt.show()

# 5. Apply K-Means
kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
data['Cluster'] = kmeans.fit_predict(X)

# 6. Display Cluster Results
print(data.head())
print("Cluster Centers:")
print(kmeans.cluster_centers_)

# 7. Visualize Clusters
sns.scatterplot(
    x=X['SepalLengthCm'],
    y=X['SepalWidthCm'],
    hue=data['Cluster'],
    palette='Set1'
)

plt.scatter(
    kmeans.cluster_centers_[:, 0],
    kmeans.cluster_centers_[:, 1],
    color='black',
    marker='X',
    s=150,
    label='Centroids'
)

plt.title("K-Means Clustering")
plt.xlabel("Sepal Length")
plt.ylabel("Sepal Width")
plt.legend()
plt.show()

### **Step 4: Elbow Method**

```
wcss = []for k in range(1, 11):    model = KMeans(n_clusters=k, random_state=42, n_init=10)    model.fit(X)    wcss.append(model.inertia_)
```

**What is the Elbow Method?**

The Elbow Method is used to determine the optimal number of clusters (K) in a dataset.

Explanation:

- `wcss = []`: Creates an empty list to store WCSS values.
- `range(1, 11)`: Tests cluster numbers from 1 to 10.
- `n_clusters=k`: Specifies the number of clusters.
- `random_state=42`: Ensures reproducible results.
- `n_init=10`: Runs K-Means with 10 different centroid initializations and selects the best result.
- `model.fit(X)`: Trains the K-Means algorithm on the dataset.
- `model.inertia_`: Returns the WCSS value.
- `wcss.append()`: Stores the WCSS value in the list.

**What is WCSS?**

WCSS stands for Within-Cluster Sum of Squares.

It measures the sum of squared distances between data points and their assigned cluster centers.

\\[ WCSS=\sum\_{i=1}^{K}\sum\_{x\in C_i} ||x-\mu_i||^2 \\]

Where:

- K = Number of clusters.
- \\(C_i\\) = Data points in cluster i.
- \\(\mu_i\\) = Centroid of cluster i.

Lower WCSS means data points are closer to their cluster centers.

**How to identify the elbow point?**

- Initially, WCSS decreases rapidly as the number of clusters increases.
- After a certain point, the decrease becomes slower.
- The point where the graph looks like an elbow is considered the optimal K.

For the Iris dataset, K = 3 is commonly selected.

## **3. Important Concepts**

### **What is Clustering?**

Clustering is an unsupervised machine learning technique used to group similar data points together.

Example: Grouping flowers based on their measurements without providing their species names.

### **What is K-Means?**

K-Means is an unsupervised learning algorithm that divides a dataset into K clusters based on similarity.

[k-means Clustering: Math Explained & Multi-Dimension Implementations | by Salah Assana | Medium](https://images.openai.com/static-rsc-4/h4LvIMKC61jb5JpetOPQMtKAbdlbX0S9TUOO8Ts4-Jd2mAGGW_qHDcEMoEL7N8pBcKcwuD681elSKzj-aaFQr_kBgCb3hBD-FeoaFNt5Gau3N_LmMBNQKyQNycvBxEdy2N0j2CaDOCpm35OqdupITIv3CNrUKoYBynzEYW8rkpA?purpose=inline)

### **How does K-Means work?**

1. Select the number of clusters (K).
2. Initialize K centroids.
3. Calculate the distance between each data point and centroids.
4. Assign each data point to its nearest centroid.
5. Recalculate the centroid of each cluster.
6. Repeat until the centroids stop changing significantly.

### **What is a Centroid?**

A centroid is the center point of a cluster. It represents the average position of all data points belonging to that cluster.

### **What is the Elbow Method?**

The Elbow Method helps determine the optimal number of clusters by plotting WCSS against different values of K.
