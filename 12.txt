import pandas as pd
import matplotlib.pyplot as plt
df = pd.read_csv("Superstore.csv", encoding="latin1")
print("First 5 Records:")
print(df.head())
print("\nDataset Shape:")
print(df.shape)
print("\nColumn Names:")
print(df.columns.tolist())
print("\nDataset Information:")
df.info()
print("\nMissing Values:")
print(df.isnull().sum())
df.columns = (
    df.columns
    .str.strip()
    .str.lower()
    .str.replace(" ", "_")
)
print("\nCleaned Column Names:")
print(df.columns.tolist())
region_sales = df.groupby("region")["sales"].sum()
print("\nTotal Sales by Region:")
print(region_sales)
plt.figure(figsize=(8, 5))
region_sales.plot(kind="bar")
plt.title("Total Sales by Region")
plt.xlabel("Region")
plt.ylabel("Sales")
plt.xticks(rotation=0)
plt.show()
plt.figure(figsize=(7, 7))
region_sales.plot(
    kind="pie",
    autopct="%1.1f%%"
)
plt.title("Sales Distribution by Region")
plt.ylabel("")
plt.show()
top_regions = region_sales.sort_values(
    ascending=False
)
print("\nTop Performing Regions:")
print(top_regions)
region_category_sales = df.groupby(
    ["region", "category"]
)["sales"].sum()
print("\nSales by Region and Category:")
print(region_category_sales)
pivot_data = df.pivot_table(
    values="sales",
    index="region",
    columns="category",
    aggfunc="sum",
    fill_value=0
)
print("\nRegion and Category Sales:")
print(pivot_data)
pivot_data.plot(
    kind="bar",
    figsize=(10, 6)
)
plt.title("Sales by Region and Category")
plt.xlabel("Region")
plt.ylabel("Sales")
plt.xticks(rotation=0)
plt.legend(title="Category")
plt.show()

## **3. Clean column names**

```

```

This code standardizes column names.

- `str.lower()`: Converts column names into lowercase.

## **4. Group sales by region**

```
region_sales = df.groupby("region")["sales"].sum()
```

This is one of the most important steps in the practical.

- `groupby("region")`: Groups records based on region.
- `["sales"]`: Selects the sales column.
- `sum()`: Calculates total sales for each region.

The result contains the total sales of each region.


## **8. Group sales by region and category**

```
region_category_sales = df.groupby(    ["region", "category"])["sales"].sum()
```

Groups the data using two columns:

- `region`: Sales region.
- `category`: Product category.
- `sum()`: Calculates total sales for each combination.

Example:

| Region | Category   | Total Sales |
| ------ | ---------- | ----------- |
| East   | Furniture  | 50000       |
| East   | Technology | 70000       |
| West   | Furniture  | 60000       |
| West   | Technology | 90000       |

*These are example values, not actual dataset results.*

**Purpose:** To understand which product categories perform well in each region.

## **9. Create pivot table**

```
pivot_data = df.pivot_table(    values="sales",    index="region",    columns="category",    aggfunc="sum",    fill_value=0)
```

Creates a summary table that organizes sales by region and category.

Explanation:

- `values="sales"`: Selects the sales values.
- `index="region"`: Displays regions as rows.
- `columns="category"`: Displays product categories as columns.
- `aggfunc="sum"`: Calculates total sales.
- `fill_value=0`: Replaces missing combinations with zero.

Example:

| Region | Furniture | Office Supplies | Technology |
| ------ | --------- | --------------- | ---------- |
| East   | 50000     | 30000           | 70000      |
| West   | 60000     | 40000           | 90000      |

*Example values for understanding.*
